    AI가 코드만 줬나요? HTML 파일로 내려받으세요

    AI가 파일을 제공했다면 바로 내려받으면 돼요. 코드만 나왔다면 HTML 전체를 아래에 붙여 넣으세요. 프롬프트가 아닌, AI가 만든 앱 코드를 넣는 곳입니다. 입력한 코드는 여기에서 실행하거나 자동 저장하지 않습니다.

    만든 파일을 함께 써 보기

    1. 내려받은 파일을 PC 브라우저로 열어 버튼과 기능을 확인하세요.
    2. 이메일·메신저의 파일 첨부 또는 공유 폴더로 .html 파일 자체를 전달하세요. 내 컴퓨터의 file:// 주소는 다른 사람에게 보내도 열리지 않아요.
    3. 받은 분은 미리보기 대신 파일을 내려받아 PC 브라우저로 열어요. 첨부나 실행이 제한되면 학교에서 허용하는 공유 방법을 사용하세요.
    4. 다른 사람의 PC에서도 동작하면 첫 공유 성공! 기록은 서로 자동으로 모이지 않아요.

    주소 공유를 선택했다면 다운로드 다음에 위 실행 안내의 게시·배포 단계까지 진행하세요. 이 파일 내려받기 버튼 자체가 인터넷에 게시하지는 않습니다.

    학생 기록을 모으는 앱은 이렇게 공유해요
    1. ‘학생 기록을 모으는 앱’을 선택해 제작 요청을 만드세요.
    2. AI가 준 열 구성대로 자신의 구글 스프레드시트를 만들고, Apps Script 코드와 HTML을 넣으세요.
    3. Apps Script를 웹앱으로 배포하고 실행 계정·접근 대상을 확인하세요. 학교 계정 정책에 따라 학생 접근이 제한될 수 있습니다.
    4. 배포된 웹앱 주소를 다른 계정으로 열어 응답 저장·교사 조회·학생별 권한을 확인한 뒤 공유하세요.

    위 HTML 게시 기능은 Apps Script 서버 코드를 실행하거나 학생 기록을 시트에 모으지 않습니다. 학생 이름·번호 입력만으로 본인 인증을 대신하지 않도록 제작 요청에 포함합니다.
